# マイナンバーカード ICチップと搭載AP

どのアプリケーション（AP）から何が取得でき、どの暗証番号が必要かを一覧するオリエンテーション用リファレンス。APDU のバイト列・AID・EF識別子・SW1SW2 は本スキルには含めず、`references/apdu-cheatsheet.md` と各APスキル（`jpki-ap-shomei` ほか）に置く。iOS からの読み取り実装手順は `ios-corenfc-apdu` を参照。

## このスキルを使う場面

- マイナンバーカードから「どの情報が取れるか／取れないか」を設計前に把握するとき
- 目的（電子署名・当人認証・基本4情報の読み取り・券面画像の取得）に対してどのAPを使うか判断するとき
- 各APの暗証番号の種類・桁数・ロック回数を確認するとき
- APDU の具体値を調べる前の見取り図が欲しいとき（具体値は `apdu-cheatsheet` へ）

## ICチップの概要

- マイナンバーカードは ISO/IEC 14443 Type-B の非接触ICカード。通信は ISO/IEC 7816-4 準拠の APDU で行う（詳細は `ios-corenfc-apdu` / `apdu-cheatsheet`）。
- ICチップは目的別に複数の **AP** に分かれる。各APは AID を指定した SELECT FILE で選択し、AP内の EF（電子証明書・秘密鍵・暗証番号・データファイル）にアクセスする。
- 秘密鍵は ICチップの格納領域から外に出ない。無理に読み出そうとするとICチップが壊れる仕組み（PDF 07）。端末側で秘密鍵・暗証番号を保持しない設計にする（`ios-security`）。
- 各暗証番号は規定回数を連続で誤入力すると閉塞（ロック）し、市区町村窓口等での初期化が必要になる（`pin-lock-handling`）。

## アプリケーション（AP）一覧

| AP | 取得できるデータ | 必要な暗証番号 | ロック回数 | 関連スキル |
|---|---|---|---|---|
| JPKI-AP（公的個人認証AP）／署名用 | 署名用電子証明書（基本4情報を含む）、秘密鍵による電子署名値 | 署名用暗証番号（6〜16桁の英数字） | 5（確認済：J-LIS `jpki.go.jp`） | jpki-ap-shomei、signature-verification |
| JPKI-AP（公的個人認証AP）／利用者証明用 | 利用者証明用電子証明書（基本4情報なし・発行番号を含む）、秘密鍵による署名値 | 利用者証明用暗証番号（4桁の数字） | 3（確認済：J-LIS `jpki.go.jp`） | jpki-ap-riyousha |
| 券面入力補助AP | 基本4情報（氏名・住所・生年月日・性別）、個人番号（いずれもテキスト） | 券面入力補助用暗証番号（4桁の数字。解錠は生年月日6桁＋有効期限4桁＋セキュリティコード4桁） | 3（確認済：マイナンバーカード総合サイト `kojinbango-card.go.jp`・マイナポータル FAQ・デジタル庁 `services.digital.go.jp`） | kenmen-nyuryoku-hojo-ap |
| 券面事項確認AP | 券面イメージ（表面・裏面）、顔写真画像、個人番号（読出しには照会番号の入力も必要） | 券面事項確認用（照合番号B・14桁＝生年月日6＋有効期限4＋セキュリティコード4）／個人番号用（照合番号A・マイナンバー12桁） | 照合番号B 10（確認済：デジタル庁・自治体・複数ベンダー資料が一致）／照合番号A 未確認 | kenmen-jikou-kakunin-ap |
| 住基AP | 住民基本台帳ネットワーク関連データ（詳細未確認） | 未確認 | 未確認 | 本スキル（専用スキルなし） |

ロック回数の列は `references/apdu-cheatsheet.md`「暗証番号の桁数・ロック回数」表に基づく（同表が数値・出典・確度の一次記録）。署名用 5 回・利用者証明用 3 回（J-LIS `jpki.go.jp`）、券面入力補助用の 4 桁 PIN 3 回（`kojinbango-card.go.jp`・デジタル庁）、券面事項確認AP の照合番号B（14 桁）10 回（デジタル庁・自治体・複数ベンダー）は一次／公的サイトで確認済。照合番号A（マイナンバー12 桁）のロック回数、および AID・EF識別子は同ファイルでも `未確認` または `（1ソースのみ・要検証）`。

## 目的別・どのAPを使うか

| 目的 | 使うAP | 備考 |
|---|---|---|
| 電子署名の生成と真正性確認（基本4情報を伴う身元確認・契約） | JPKI-AP／署名用 | `jpki-ap-shomei`。本人確認方法上の位置づけは `honnin-kakunin-houhou` を参照 |
| ログイン等の当人認証（基本4情報は不要） | JPKI-AP／利用者証明用 | `jpki-ap-riyousha`。発行番号でログイン者を特定 |
| 基本4情報・個人番号をテキストで読み取る（券面撮影・容貌撮影と組み合わせる方法） | 券面入力補助AP | `kenmen-nyuryoku-hojo-ap`。方法の詳細は `honnin-kakunin-houhou` を参照。署名機能はなく読み取り専用 |
| 券面イメージ・顔写真画像・個人番号を読み取る（対面確認、本人確認書類のIC読取） | 券面事項確認AP | `kenmen-jikou-kakunin-ap`。個人番号の取扱いは番号法の根拠が必要 |
| 住民基本台帳ネットワーク関連の処理 | 住基AP | 本プラグインでは詳細対象外 |

## 未確認事項

- 各APのAID実値。JPKI-AP のみ複数ソースで一致。券面入力補助AP は公開1ソースのみで要検証、券面事項確認AP・住基AP は公開ソースで確認できず。実値は `references/apdu-cheatsheet.md` を参照（実装前に要検証）。
- 各APの EF レイアウト（電子証明書・秘密鍵・暗証番号・データファイルの識別子の網羅リスト）。
- ロック回数で未確認なのは照合番号A（マイナンバー12桁・個人番号用）と住基用。署名用 5 回・利用者証明用 3 回（J-LIS `jpki.go.jp`）、券面入力補助用の 4 桁 PIN 3 回（`kojinbango-card.go.jp`・デジタル庁）、照合番号B（14桁）10 回（デジタル庁・自治体・複数ベンダー）は確認済（`references/apdu-cheatsheet.md`）。照合番号A のロック回数と AID・EF識別子は公開ソースになく、J-LIS の技術仕様（NDA）での確認が必要。
- 券面入力補助用暗証番号の解錠パラメータ（生年月日6桁＋有効期限4桁＋セキュリティコード4桁）の構成とバイト順。
- 住基AP で取得できるデータ項目の詳細と用途。
