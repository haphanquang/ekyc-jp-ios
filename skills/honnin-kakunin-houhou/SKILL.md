# 本人確認方法マップ（犯収法・携帯法・古物営業法）

日本の非対面 eKYC で「適用法令ごとに、いつ、どの本人確認方法が使えるか」を判断するためのリファレンス。

**このスキルと `references/method-map.md` が、方法の名称（イ〜ヨ 等の号記号）と施行時期を定義する唯一の場所。** 他スキルは本スキル／`method-map.md` を参照し、名称・時期を各自で断定しないこと。方法の一覧表（記号・取得データ・対応書類）は `references/method-map.md` が正本であり、本スキルはその上に「いつ・どれを実装するか」の判断を重ねる層である。

- 一覧表・取得データ・対応書類 → `references/method-map.md`
- 号記号の一次条文抜粋（e-Gov リビジョン ID 付き） → `references/hourei-eKYC.md`
- 施行規則の逐条・新旧対照 → e-Gov 法令検索（`## 出典`）

## このスキルを使う場面

- eKYC / 本人確認機能の法的根拠（犯収法 / 携帯法 / 番号法 / 古物営業法）を特定し、使える方法を洗い出すとき
- 「ホ方式（書類撮影＋セルフィー）」が今後も使えるか、いつまで使えるかを判断するとき
- 2027年4月の犯収法改正で自社フローがどう影響を受けるかを確認するとき
- 公的個人認証（JPKI）方式を使うために自社が「署名検証者」である必要があるかを確認するとき
- 実装する方法を1つ以上選定するとき（本スキル `## このアプリでの推奨` と `## 目的別・方法選定フロー`）
- 他スキル・設計書に「◯方式は◯年に廃止」等と書く前の裏取り

## 現行の方法（犯収法）

犯罪による収益の移転防止に関する法律施行規則 第6条第1項第1号の、個人（自然人）向け・非対面／電磁的方法。号記号は **イ〜ヨ の 15 号**。**記号・取得データ・対応書類の一覧は `references/method-map.md`「現行（在効）犯収法の個人向け方法」の表を参照。** 一次条文抜粋は `references/hourei-eKYC.md` §1（リビジョン `420M60000F5A001_20260806_508M60000F5A006`）。以下は eKYC で実装対象になりうる主な号の概要のみ。

| 記号 | 概要 | 2027年4月改正後 |
|---|---|---|
| ホ | 写真付き本人確認書類の**画像**の送信 ＋ 容貌撮影（いわゆる「ホ方式」） | **廃止** |
| ヘ | 写真付き本人確認書類の **IC チップ記録情報**の送信 ＋ 容貌撮影 | 号記号 **新ハ**（IC 読取＋容貌）へ移行 |
| ト | 書類の画像送信 又は IC 読取 ＋ 銀行等への顧客情報照会（銀行 API） | 画像送信型は廃止、IC 読取型は存置（新ニ 相当） |
| チ | 書類の提示・送付 ＋ 取引関係文書を転送不要郵便物等として送付 | 号記号が移動 |
| ワ | 電子署名法第4条第1項の**認定認証事業者**の電子証明書 ＋ 電子署名情報の送信 | 号記号 **新リ** 相当。JPKI とは別の独立した方法（「カの旧称」ではない） |
| カ | **公的個人認証（JPKI）** ＝ 機構発行の署名用電子証明書 ＋ 電子署名が行われた特定取引等に関する情報の送信。基本4情報（氏名・住居・生年月日・性別）を取得。**但書＝特定事業者が署名検証者である場合に限る**（下記） | 存置。号記号 **新ヌ**（但書も同一） |
| ヨ | 公的個人認証法第17条第1項第5号認定者（**特定認証業務**）の電子証明書 ＋ 電子署名情報の送信 | 号記号 **新ル** 相当。JPKI とは別 |
| ル | **カード代替電磁的記録**（スマートフォンに搭載したマイナンバーカード）の**特定電磁的記録**の送信 ＋ 帰属確認。2025年6月24日新設。容貌画像の送信は不要 | 存置。号記号 **新ト** |

- **ル方式の特定電磁的記録に含まれるのは「氏名・住居・生年月日・写真」のみで、個人番号・性別は含まれない**（施行規則第6条第1項第1号ルの定義）。個人番号を取得・保存する設計にしないこと（番号法上の事務根拠が別途必要。`kenmen-jikou-kakunin-ap`）。
- ル方式は対面・非対面いずれの特定取引でも利用可。原則15歳以上。Android版マイナンバーカードは2026年秋頃提供予定。

### カ方式（JPKI）を使うには自社が「署名検証者」であること

犯収法施行規則第6条第1項第1号カ（2027年4月以降は新ヌ）の条文末尾に但書がある（`references/hourei-eKYC.md` §1 に verbatim）:

> …特定事業者が公的個人認証法第十七条第四項に規定する署名検証者である場合に限る。

- 「署名検証者」＝ 公的個人認証法第17条第1項の**届出をした者**（民間事業者は同項**第6号の主務大臣認定**を受けたうえで届出をした者）＋機構（同法第17条第4項）。
- JPKI 方式で**取引時確認**を行うには、**特定事業者自身が署名検証者**である必要がある。「PF事業者が認定を持っているから SP事業者は認定不要」という一般論は、有効性確認の設備・照会を PF事業者に委託できるという意味であって、カ方式（新ヌ）を取引時確認に使う特定事業者は署名検証者でなければならない。
- PF事業者は主務大臣認定・機構への届出・署名検証設備の整備を特定事業者に代わって行える（`platform-jigyousha`）が、名義は特定事業者に帰属する。
- **設計・契約前のブロッキング項目**: 自社が署名検証者になる必要の有無、PF事業者が代行できる範囲、必要な期間を、法務・PF事業者に確認する（`platform-jigyousha` のオンボーディング）。

### 確認済みの事実

- **施行日は令和9年（2027年）4月1日。** 警察庁 JAFIC「令和8年改正…（令和8年3月6日公布）に関するQ&A」Q2、金融庁の公布資料（令和8年6月26日）がいずれも明記。
- **号記号は再編され、イ〜カ の 14 号になる。** e-Gov `?asof=2027-04-01` から取得した各号の要旨は `references/method-map.md`「## 2027年4月1日 施行」の表を参照。主な対応: **現ヘ → 新ハ**（非対面 IC 読取＋容貌）、**現ル → 新ト**（スマホ搭載マイナンバーカード）、**現カ → 新ヌ**（JPKI、但書同一）、現ワ → 新リ、現ヨ → 新ル。
- **なりすましリスクの高い方法を号を特定して廃止。** (a) 写真付き本人確認書類を撮影した**画像**の送信を受ける方法（いわゆる「ホ方式」）、(b) 本人確認書類の**写しの送付**を受ける方法のうち画像送信型・写真のない書類型。**写し送付＋転送不要郵便の類型は号を分けて存置**（「写しの送付は全廃」ではない）（ただし新ヘは対象取引が限定、新ワ・新カは住民基本台帳法の適用を受けない者・国外転出者に限る。2027年版 第6条第1項第1号ワ柱書「以下ワ及びカにおいて同じ」、リビジョン `420M60000F5A001_20270401_508M60000F5A005`、取得日 2026-10-05）。
- **非対面は「IC チップ情報の読み取り ＋ 券面情報との照合」へ移行。** 省庁提供アプリに限らず民間アプリも可。
- **補完措置を存置。** IC チップ付き書類を持たない者へ、偽造防止措置のある本人確認書類（住民票の写し等）の原本送付＋転送不要郵便。
- **施行前に適法完了した取引時確認は有効**（「済み確認」。やり直し不要）。

### 古物営業法

一次条文抜粋: `references/hourei-eKYC.md` §5（古物営業法施行規則 リビジョン `407M50400000010_20260812_508M60400000017`、古物営業法 `324AC0000000108_20250601_504AC0000000068`、取得日 2026-10-05）。各号と犯収法の対応表は `references/method-map.md`「## 古物営業法」を参照。

- 確認義務は古物営業法第15条第1項（第1号〜第4号のいずれか）。第4号の委任を受けた**施行規則第15条第3項は 一〜十三 の 13 号**（漢数字。犯収法のイ・ロ…とは別体系）。確認事項は**住所・氏名・職業・年齢**。
- 主な対応: **第十一号 ≈ 犯収法カ（新ヌ）＝ JPKI**、**第九号 ≈ ヘ（新ハ）＝ IC 読取＋容貌**、第八号 ≈ ホ（書類画像＋容貌）、第四号 ≈ チ（新ホ）＝ IC・画像送信／住民票の写し等の送付＋転送不要郵便（ト型ではない）、第五号 ≈ リ（新カは住基法適用外・国外転出者に限る）、第十二号 ≈ ヨ（新ル）。
- **第十一号（JPKI）にも署名検証者の但書がある**（「当該古物商が公的個人認証法第十七条第四項に規定する署名検証者である場合に限る」）。電子署名された記録には相手方の**住所、氏名、職業及び年齢**が含まれていなければならない（署名用電子証明書の基本4情報に職業は無い）。移動端末設備用署名用電子証明書（公的個人認証法第16条の2第6項）も対象。
- **スマホ搭載マイナンバーカードの特定電磁的記録を送信する方法（犯収法ル／新ト型）は無い。**
- **2027年**: 2026-10-05 時点の e-Gov では古物営業法施行規則に未施行の改正リビジョンは無く、`?asof=2027-04-01` も現行リビジョンを返す（第八号の書類画像型も e-Gov 上は在効のまま）。今後の改正有無は未確認。
- 記録: 帳簿等への記載（本法第16条。相手方の住所・氏名・職業・年齢、とった措置の区分）と 3 年保存（本法第18条第1項）。犯収法の確認記録（7 年）とは別。

## 確認記録の作成・保存

犯収法上、**特定事業者は取引時確認を行ったら直ちに確認記録を作成し、一定期間保存しなければならない**。eKYC の実装では、方式選定と同じ重さでこの記録義務を設計に織り込む。

- **確認記録**（犯収法 第6条第2項）: 取引時確認を行った場合に直ちに作成し、**特定取引等に係る契約が終了した日その他の主務省令で定める日から 7 年間**保存する（施行規則第21条は「取引終了日及び取引時確認済みの取引に係る取引終了日のうち**後に到来する日**」とする）。
- **取引記録等**（犯収法 第7条第3項）: 特定業務に係る取引等を行った場合に作成し、**当該取引等が行われた日から 7 年間**保存する。
- **電磁的記録の添付義務**（施行規則第19条第1項第2号）: 第6条第1項第1号の **ワ〜ヨ**（ワ・カ・ヨ。カ＝JPKI を含む。2027年以降は リ〜ル に相当）の方法で確認したときは、確認記録に「当該方法により本人特定事項の確認を行ったことを証するに足りる電磁的記録」（実務上は電子署名と署名用電子証明書）を添付する。**ヘ方式（IC 読取＋容貌）**では「本人確認用画像情報 ＋ IC チップに記録された氏名・住居・生年月日・写真の情報」を添付する。
  - → **「最新4情報提供サービスの同意取得では署名用電子証明書を保持しない」という原則（`doui-jouhou-kanri`）は、この犯収法の証跡添付義務とは別制度。** カ方式（新ヌ）で取引時確認を行う場合は、犯収法の証跡ストア（電子署名＋署名用電子証明書、7 年）と、同意情報ストア（10 年・非保持）を**別に設計する**（`signature-verification`「検証後に保持するもの／しないもの」）。
- **起算日に注意**: 確認記録は「取引開始時」ではなく「契約が終了した日等」から 7 年。継続的な契約関係では保存期間が実質的に延びる。
- eKYC セッションの監査ログ（`ekyc-session-orchestration`）、電子証明書の有効性確認の証跡（`jlis-yukousei-kakunin`）は、この確認記録・取引記録の一部または裏付けになり得る。サーバー側の保存設計をこれらのスキルと整合させる。
- **同意情報の有効期間 10 年（`doui-jouhou-kanri`）は別制度**（最新の利用者情報（4情報）提供サービスの本人同意）。犯収法の記録保存 7 年とは根拠条文・起算日・対象が異なるので混同しない。
- 確認記録に記載すべき事項の詳細は施行規則第20条（31 号）、作成方法・添付資料は第19条で確認する。古物営業法は確認記録ではなく帳簿等（本法第16条・第18条、3 年保存。`references/hourei-eKYC.md` §5）。携帯法の記録義務の細目は `## 未確認事項`。

## このアプリでの推奨

**基本は カ方式（公的個人認証 / JPKI ＝ 現カ、2027年以降は新ヌ）を中心に据える。**

- 署名用電子証明書で基本4情報（氏名・住居・生年月日・性別）を取得でき、2027年4月改正後も存置される（新ヌ）。J-LIS へ有効性を照会（PF事業者経由）し電子署名を検証する（`jpki-overview` / `jlis-yukousei-kakunin`）。
- 犯収法・携帯法（現ト）・古物営業法（施行規則第15条第3項第十一号）のいずれにも JPKI の方法があり、法令横断で単一フローを維持しやすい。ただし古物営業法では電子署名の対象に住所・氏名・職業・年齢の記録が必要（`references/method-map.md`「## 古物営業法」）。
- **ただし但書に注意**: 取引時確認に使うには自社が署名検証者であること（上記「## カ方式（JPKI）を使うには…」）。

**離脱率対策の併用として ヘ方式（IC チップ読取＋容貌撮影 ＝ 現ヘ、2027年以降は新ハ）をフォールバックに用意する。**

- 署名用電子証明書のパスワード（6〜16桁の英数字、5回ロック）や有効期限切れ・未発行で JPKI を完了できない利用者向けの受け皿。
- IC 読取方式のため 2027年4月改正後も新ハ（IC 読取＋容貌）として存置。
- **IC 内顔写真は券面事項入力補助APには無い**。基本4情報＝券面事項入力補助AP（`kenmen-nyuryoku-hojo-ap`）、IC 内顔写真＝券面事項確認AP（`kenmen-jikou-kakunin-ap`）を組み合わせる。
- LIQUID資料も「画像撮影による本人確認（ホ方式等）に近い離脱率を維持するには ヘ方式の導入が鍵」とする（ベンダー見解）。

**画像撮影のみの方式（ホ方式等）を犯収法の主経路にしない。** 2027年4月1日で犯収法上は使えなくなる。犯収法以外の用途に限って検討する。
